# Blitzy Sandbox

Welcome to the **Blitzy Sandbox** developer portal — a showcase of AI-generated codebases across multiple languages and frameworks.

## What is this?

Blitzy Sandbox is a Backstage-based developer portal that catalogs over 50 open-source projects generated by [Blitzy](https://blitzy.com), an AI-powered software development platform. The portal itself is a live demo: the original Backstage Material UI components have been migrated to shadcn/ui, covering 88.8% of 154 plugins.

When you open the portal, the root URL `/` automatically redirects to the catalog. There is no separate dashboard or welcome page; the catalog is the landing surface. Primary navigation lives in the top-right corner of every page header: a non-interactive Blitzy logo, a Settings icon, and a Support icon (whose popover surfaces the GitHub Issues link and the official Blitzy support email `support@blitzy.com`).

## What you'll find here

- **Software Catalog** — Browse all Blitzy-generated projects organized by language (TypeScript, Rust, Python, Go, C/C++, .NET, Java)
- **TechDocs** — Per-project documentation accessible via the Documentation tab on each entity page. There is no global Documentation index in primary navigation.
- **Project Insights** — GitHub integration showing repo stats, CI status, and contribution activity
- **Access control** — Catalog browsing is open to all signed-in users and Guest sessions; write actions (refresh, register, delete) require a verified `@blitzy.com` GitHub email. See [Getting Started](getting-started.md) for details.
